£ EdUp 🚀

EdUp is a career transformation platform for people who want to **retrain**, **change careers**, or **accelerate career growth**.  
This repo contains the frontend built with **Vite + React** and a demo-style progress system used for showcasing the product without a backend.

---

## ✨ Features (Current)
- **Home** landing page with pathway navigation
- **Retrain** page with career cards and journey start CTA
- **Change Career** page (UI)
- **Career Planning** page (UI)
- **MyLab Dashboard** (demo progress tracking)
  - progress ring
  - resources list (with placeholder progress)
  - application timeline (toggle milestones)
  - upcoming sessions (demo bookings)

---

## 🧱 Tech Stack
- **React (Vite)**
- **React Router**
- **CSS Modules / standard CSS files**
- Demo progress stored using **localStorage** (for placeholder tracking)
